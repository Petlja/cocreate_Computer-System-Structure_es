# Suplemento para maestros

Aquí van las información para los maestros.
Consejos sobre cómo usar markdown son útiles para saber cómo formatear el documento. Más información está [aquí](https://www.markdownguide.org/cheat-sheet/).

Un componente expandible que se puede agregar a las mismas páginas que leen los estudiantes se define así:

```{learnmorenote} Texto siempre visible

Contenido adicional que se ve solo cuando haces clic en la flecha para expandir
```

Nota: En la vista previa de GitHub nada parece expandible. El curso debe ser "compilado" y publicado para verlo (o se deben instalar localmente herramientas que hagan una vista previa completa, lo cual no es opcional).
